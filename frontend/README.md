# VyapaarPilot Frontend

Flutter application for the VyapaarPilot AI business growth assistant.

## Features
- **Modern Indian Fintech Design**: Clean white card surfaces (`#FFFFFF`), Deep Navy primary color (`#123B66`), Light Blue info states (`#E8F3FF`), and high contrast financial metrics.
- **Responsive Layout**: Adapts dynamically across Mobile (`<600px`), Tablet (`600-1024px`), and Desktop (`>1024px`).
- **Core Screen Navigation**:
  - `DashboardScreen`: Summary metrics & active underperformance opportunities.
  - `OpportunityDetailScreen`: Tuesday slowdown breakdown & AI recommendations.
  - `ExperimentScreen`: Promo experiment simulator & +25% uplift outcome.
  - `AssistantScreen`: Interactive AI merchant Q&A.

## Development Setup

```bash
flutter pub get
flutter analyze
flutter run -d chrome  # Or macOS / Android / iOS
```
